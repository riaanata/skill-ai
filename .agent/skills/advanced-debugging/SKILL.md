# Advanced Debugging

1. Reproduce the issue safely.
2. Capture exact error, logs, inputs, and environment.
3. Trace execution path and recent changes.
4. Form a root-cause hypothesis and verify it.
5. Identify affected modules and possible regressions.
6. Propose the smallest safe fix.
7. Implement only relevant changes.
8. Add a regression test.
9. Run targeted tests, then broader checks.
10. Report remaining uncertainty.

Never suppress exceptions, weaken validation, or disable tests as a substitute for fixing the cause.

# Frontend Engineering

- Follow existing framework and component conventions.
- Use strict types and avoid unsafe casts.
- Separate presentation from business logic where practical.
- Handle loading, empty, error, success, and disabled states.
- Validate UX on narrow and wide viewports.
- Use semantic HTML and keyboard-accessible controls.
- Avoid exposing secrets or trusting client-side authorization.
- Avoid unnecessary state and re-renders.
- Test critical user journeys and form validation.
- Do not introduce a design system or dependency without need.

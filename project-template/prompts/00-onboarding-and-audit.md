# Prompt — Onboarding and Safe Project Audit

Act as a Principal Software Architect. First read `AGENTS.md`, `GEMINI.md`, `PROJECT.md`, and the relevant docs.

Do not modify application code yet.

Inspect repository structure, stack, dependencies, main modules, data flows, database, API contracts, authentication/authorization, tests, CI, deployment, and security-sensitive areas.

Create `docs/PROJECT_AUDIT.md` with scope, architecture summary, evidence-based findings, severity, risks, and a prioritized plan. Clearly distinguish verified facts from assumptions and items not inspected.

Preserve all existing work. Ask before destructive or production actions. Finish by summarizing findings and waiting for approval.

# Prompt — Review Current Git Diff

Review `git diff` and relevant surrounding code. Do not modify files during the review.

Find correctness defects, security issues, data-integrity risks, concurrency problems, API/schema incompatibilities, performance problems, missing tests, and maintainability concerns.

For each finding include severity, file/line, evidence, impact, and suggested fix. Separate blockers from suggestions. State what was not reviewed. Do not approve unresolved critical/high issues.

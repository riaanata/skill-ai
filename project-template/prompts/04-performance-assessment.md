# Prompt — Evidence-Based Performance Assessment

Assess [TARGET / SYMPTOM].

Establish a baseline and measure before optimizing. Inspect frontend rendering/bundle, API latency, database query plans, N+1 patterns, memory, concurrency, caching, payload size, and external dependencies as relevant.

Identify bottlenecks with evidence. Propose prioritized optimizations and trade-offs. Implement approved changes only, then re-measure and run regression tests. Report before/after measurements and test evidence. Do not invent benchmark numbers.

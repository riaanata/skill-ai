# Prompt — Safe Database Change

Requested data/schema change: [DESCRIBE]

Inspect schema, ORM models, queries, constraints, data volume, and all affected application paths. Propose migration, compatibility strategy, lock/downtime risk, backfill, validation, and recovery plan.

Use non-production data for testing. Do not execute against production or perform destructive data operations without explicit approval and verified backup/recovery. Update schema docs and tests. Report migration commands and observed results.

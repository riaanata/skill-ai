# Definition of Done Checklist

- [ ] Acceptance criteria met
- [ ] Existing conventions followed
- [ ] Authorization/input validation considered
- [ ] Error/loading/empty states handled
- [ ] Tests added or updated
- [ ] Relevant tests executed
- [ ] Lint/typecheck/build executed where available
- [ ] Diff reviewed; unrelated changes removed
- [ ] API/database docs updated if needed
- [ ] Migration and rollback considered
- [ ] No secrets or sensitive data exposed
- [ ] Risks and unverified checks reported
